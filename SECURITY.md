# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in `corgspace/hmac-http-client`, please report it privately through GitHub's [Security Advisories](https://github.com/CorgSpace/hmac-http-client/security/advisories/new) form. Do not open a public issue.

Please include:

- A description of the issue and its impact.
- Steps to reproduce (proof of concept welcome).
- Affected versions, if known.

You will receive an acknowledgement within 7 days. Once confirmed, a fix will be prepared and disclosed alongside the release notes.
